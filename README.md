# Mi Día $5.000

Aplicación web instalable (PWA) para registrar gastos diarios.

## Publicar en GitHub Pages

Sube el contenido de esta carpeta directamente a la raíz de la rama `main` y configura Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Funciones
- Calendario mensual para seleccionar cada fecha.
- Presupuesto automático de $5.000 por día.
- Presupuesto personalizado para fechas especiales.
- Registro y eliminación de gastos.
- Totales diarios y saldo disponible.
- Respaldo e importación de datos en JSON.
- Almacenamiento local en el dispositivo y funcionamiento offline después de la primera carga.

Los datos se guardan en el almacenamiento local del navegador. No se envían a un servidor.
